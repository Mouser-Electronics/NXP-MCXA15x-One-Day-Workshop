# Workshop Schedule

Assumes MCUXpresso IDE and the board SDK are installed before class.

| Time | Activity | Duration |
|---|---|---:|
| 8:30-8:50 | Welcome, board check, repository access | 20 min |
| 8:50-10:00 | Module 1: GPIO and first debug session | 70 min |
| 10:00-10:15 | Break | 15 min |
| 10:15-11:15 | Module 2: PWM and RGB LED | 60 min |
| 11:15-12:30 | Module 3: Temperature and CSV | 75 min |
| 12:30-1:15 | Lunch | 45 min |
| 1:15-2:25 | Module 4: Interrupts and events | 70 min |
| 2:25-2:40 | Break | 15 min |
| 2:40-4:20 | Module 5: Capstone | 100 min |
| 4:20-5:00 | Validation, troubleshooting, review | 40 min |

Total scheduled time: 8 hours 30 minutes.

Add 45-75 minutes if software must be installed during the workshop. A better classroom policy is to distribute a setup checklist in advance and reserve only 20 minutes for verification.
